# The MCP server has no model of its own

Supersedes [ADR 0002](0002-langgraph-inside-mcp-tool.md) and the retrieval plan in [ADR 0003](0003-defer-retrieval-to-measured-experiment.md). The goal changed: this project now targets producers, not developers, and an Anthropic API key — sign up, add billing, generate a key, paste it into a config file — is the single biggest barrier to a non-technical producer ever trying it. ADR 0002 chose a self-contained pipeline (its own LLM call per request) for testability, prompt/retry control, and uniform behaviour across MCP clients; those benefits are real but matter less than removing the signup wall. The MCP tools now take a `Patch` directly: the calling client (whatever model the producer is already chatting with, already paid for) does the sound-design reasoning itself, guided by the server's tool descriptions and a `list_parameters()` tool; the server only validates and writes. There is no longer any LLM call, API key, or model/provider configuration anywhere in this codebase.

**Consequences:** `serum-gen "<description>"` and `serum-gen revise` (CLI) are removed — they only existed to drive the pipeline from a terminal, and re-adding a model just to keep them would undo the point of this change. The CLI keeps only `inspect` (pure code, unaffected). Ticket 07 (local model option) and ticket 09 (eval set, as scoped against pipeline quality) are moot; 07 is closed wontfix. Revisions work the same way: an edit tool takes a partial `Patch` update, not feedback text.
